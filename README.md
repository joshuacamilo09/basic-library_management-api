# Library API

A training REST API built with **Java + Spring Boot** for managing books in a library system.

The goal of this project is to practice backend development concepts such as CRUD operations, DTOs, pagination, filtering, business rules, global exception handling and API documentation with Swagger/OpenAPI.

## Tech Stack

- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- Bean Validation
- Lombok
- Swagger / OpenAPI
- Maven

## Features

- Create books
- List books with pagination
- Get book by ID
- Update book information
- Delete books
- Loan available books
- Return loaned books
- List available books
- List active loans
- Global exception handling
- Swagger API documentation
